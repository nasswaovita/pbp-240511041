# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C++, C#, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, pengguna mengakses melalui browser | Berjalan langsung pada sistem operasi komputer | Native atau hybrid yang berjalan pada perangkat mobile |
| Cara distribusi | Melalui website atau URL | Melalui installer seperti .exe atau .msi | Melalui Play Store atau App Store |
| Keunggulan | Mudah diakses, tidak perlu instalasi, dapat digunakan berbagai perangkat | Performa tinggi dan dapat mengakses sumber daya komputer secara maksimal | Praktis, mudah dibawa, dan memanfaatkan fitur smartphone |
| Keterbatasan | Bergantung pada browser dan koneksi internet | Harus melakukan instalasi pada setiap perangkat | Terbatas oleh spesifikasi perangkat dan sistem operasi |
| Contoh aplikasi | Google Docs, YouTube, Gmail | Microsoft Word, Visual Studio Code, Adobe Photoshop | WhatsApp, Instagram, Gojek |
